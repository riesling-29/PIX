# 아키텍처

이 디렉토리는:

- 정본 PIX 아키텍처
- 구현이 존재할 때 현재 구현 아키텍처;
- 아키텍처는 실제 결정을 내릴 때 의사결정을 기록합니다.
- 의존성과 책임의 경계가 있습니다.

아키텍처 문서는 의도된 또는 승인된 구조를 설명합니다. 그들은 어떤 구현이 완료되었음을 증명하지 않습니다.

여기에 추측적인 아키텍처 결정 기록이 만들어서는 안 됩니다.

# Architecture

This directory owns:

- the canonical PIX architecture;
- the current implementation architecture when an implementation exists;
- architecture decision records when real decisions are made;
- dependency and responsibility boundaries.

Architecture documents describe intended or accepted structure. They do not prove that any implementation has been completed.

No speculative architecture decision records should be created here.
