# 명령어

이 디렉토리는 개발 명령어, 검증 명령어 및 약속 준비 체크리스트를 검토합니다.

명령은 명령이 아니라 구현이 존재하거나 지시된 작업이 완료되었다는 증거가 아닙니다.

# Prompts

This directory stores reviewed development prompts, verification prompts, and commit-readiness checklists.

Prompts are instructions, not evidence that an implementation exists or that the instructed work has been completed.
