# PM4Py 및 OCPA 비교

이 디렉토리는 각 프로젝트의 개별 기준선 분석이 완료된 후에 PM4Py과 OCPA을 비교합니다.

계획된 비교 크기는 다음과 같습니다.

- 데이터 계약
- OCEL 지원
- 이벤트 객체와 객체 객체 관계
- 객체 투영
- 발자국 재구성
- 시간적 의미론
- 라이프 사이클 의미론
- 증거나 출처 계보
- 결과 계약
- 오류 및 사용할 수 없는 상태의 의미론
- 결정론
- 의존성 비용
- 테스트 가능성
- 라이선스 제공
- PIX에 적합성

비교결과는 다음을 구분해야 한다.

- 확인된 사실
- 관찰된 행동
- 해석
- 가설
- 해결되지 않은 문제
- 입양 결정
- 탈퇴 조건.

실제 비교 보고서는 이 초기화의 범위에 속하지 않습니다.

# PM4Py and OCPA Comparison

This directory compares PM4Py and OCPA only after the individual baseline analysis for each project has been completed.

Planned comparison dimensions are:

- data contracts;
- OCEL support;
- event-object and object-object relations;
- object projection;
- trace reconstruction;
- temporal semantics;
- lifecycle semantics;
- evidence or provenance lineage;
- result contracts;
- error and unavailable-state semantics;
- determinism;
- dependency cost;
- testability;
- licensing;
- suitability for PIX.

Comparison conclusions must distinguish:

- confirmed facts;
- observed behavior;
- interpretation;
- hypothesis;
- unresolved issue;
- adoption decision;
- withdrawal condition.

The actual comparison report is outside the scope of this initialization.
